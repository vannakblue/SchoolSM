ការកំណត់លើម៉ាស៊ីន ZKTeco៖
  1. ចូល Menu លើម៉ាស៊ីន ➔ Comm. (Communication) ➔ Cloud Server Setting
  2. ដាក់ Server Address ទៅកាន់ IP ឬ Domain របស់សាលា
  3. ដាក់ Port (ឧ. 80 ឬ 8000) និង Secret Token ដូចក្នុងប្រព័ន្ធ
