# Autonomous Execution & Auto-Submit Guideline

- Automatically execute all necessary terminal commands, file edits, and tool calls to complete the user's task.
- Do not stop to request review or confirmation for standard commands (e.g. running unit tests, executing scripts, applying edits).
- Do not enter interactive planning mode requiring user feedback unless explicitly instructed by the user.
- Execute directly, verify the outcome, and report completed results concisely.
